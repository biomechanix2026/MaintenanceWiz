# Tech Stack

## Language
- **Python:** Primary programming language used across the stack (data, ML, application, and orchestration layers).

## Frontend
- **Streamlit:** Used for the five-panel industrial dashboard.

## Backend & AI
- **scikit-learn & shap:** Used for the Machine Learning Prognostics layer (Remaining Useful Life and explainability).
- **Anthropic (Claude):** Powers the reasoning engine and tool-use loop ("Consolidated Brain").
- **Pandas & Numpy:** Core libraries for data manipulation and deterministic fallback pipelines.

## Database & Storage
- **ChromaDB:** Vector store for the Retrieval-Augmented Generation (RAG) system handling equipment manuals.
- **SQLite (In-Memory):** Used for querying structured enterprise data (like ERP spares and incident logs).
